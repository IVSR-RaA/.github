# IVSR-RaA

## About

We focuses on autonomous robotic systems for multi-robot exploration, 3D mapping, SLAM, and communication-aware collaboration.

The main research direction is building heterogeneous UAV–UGV systems that can operate in unknown, large-scale, GPS-denied, and communication-limited environments.

## Research Focus

### Multi-Robot Exploration

We develop exploration pipelines that allow multiple robots to coordinate, share information, and build a common map of unknown environments.

Main topics:

- UAV–UGV collaborative exploration
- Multi-agent coordination
- Graph-based exploration
- Shared map construction
- Exploration under communication constraints

### SLAM and 3D Mapping

We work on LiDAR-based SLAM and 3D map representations for autonomous navigation and map fusion.

Main topics:

- LiDAR odometry
- Point cloud processing
- Voxel mapping
- Occupancy mapping
- Loop closure
- Multi-robot map fusion

### Opportunistic Communication

We develop communication-aware systems for robots operating with unstable or intermittent wireless links.

Main topics:

- Store-and-forward communication
- Robot-to-robot data exchange
- RSSI-based communication triggering
- Keyframe sharing
- Low-bandwidth map transmission

### Learning-Based Map Compression

We investigate neural compression methods for reducing bandwidth requirements in multi-robot map sharing.

Main topics:

- VAE-based LiDAR compression
- Range image encoding
- Latent vector keyframes
- Reconstructed point cloud generation
- Bandwidth-efficient map sharing
