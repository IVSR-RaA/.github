# IVSR-RaA

We develop ROS-based robotics systems for multi-robot exploration, SLAM, and communication-constrained mapping.

## Main projects

- Multi-robot exploration with UAV/UGV agents
- 3D LiDAR mapping and voxel-based map representation
- Point cloud compression using VAE for intermittent communication

## Tech stack

ROS1, ROS2, Gazebo, PX4, LiDAR SLAM, C++, Python
